## CAT2RIG 1.5.0 – 41 radios / 41 radiów

**English** · [Polski ↓](#polski)

The radio catalogue was checked against the [Hamlib 4.7.1 list](https://github.com/Hamlib/Hamlib/wiki/Supported-Radios) and extended to **41 models**.

### New radios
- **Icom:** IC-7200, IC-7410, IC-7600, IC-9100, IC-746PRO, IC-756PROIII
- **Xiegu:** X108G
- **Yaesu:** FTDX5000, FTDX3000, FTDX1200, FT-2000
- **Elecraft:** K2 · **QRP Labs:** QDX/QCX/QMX · **(tr)uSDX**

### Also new
- **✓** in the model list marks radios verified on real hardware
- Each model shows its **Hamlib model number** (`rigctl -l`) in the documentation
- New wiki page **[Supported Radios](https://github.com/SP5XTF/CAT2RIG/wiki/Supported-Radios)**
- 81 automated tests

### Please test
Verified on real hardware: **Icom IC-706MKIIG**. The new models use protocols CAT2RIG already supports, but haven't been tried on the radios yet. If you own one, please [open an issue](https://github.com/SP5XTF/CAT2RIG/issues/new/choose) with the log (*Show CAT frames* ticked).
